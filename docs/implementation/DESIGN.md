# Classroom interface

Cathedra uses an operating interface for an instructor during class. The room remains visible beside the student directory.

The interface uses white surfaces, a pale gray canvas, blue selection, system sans-serif text, and Phosphor icons. Desktop panels separate sections, students, and seat details. Mobile controls expose the directory and seat details as drawers. Native dialogs contain record forms and confirmations.

The 3D room uses generated geometry. Estimated model units use a 13 by 15 floor, 1.45 desk spacing, and 1.75 row spacing. These are visual proportions, not measured dimensions. The instructor faces positive Z. Positive X appears on the instructor left. Left and right identify physical blocks and never change with camera movement.

The cutaway omits the ceiling. Window frames, pale wood desks, monitors, towers, chairs, tiles, and the front desk provide room references. The supplied photos are not application assets. Selection uses blue accents. Names appear on hover, selection, or an explicit toggle.

The default camera shows an elevated overview. Instructor, Top-down, and Focus are explicit actions. Seat selection preserves the camera. Desktop navigation requires Space. Touch devices expose a navigation toggle.
