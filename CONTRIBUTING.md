# Contributing

Every ordinary change to this project requires an Issue, a branch, and a Pull Request.

## Setup
```bash
npm install
```

## Validation
```bash
npm run lint
npm run build
npm test
```

## Pull Request Workflow
1. Create a branch from `main` using `<type>/<issue-number>-<short-description>`.
2. Follow Conventional Commits.
3. Validate your changes using the commands above.
4. Create a PR targeting `main` and include `Closes #<issue-number>`.
